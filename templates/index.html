Network Forensic Analysis of a RIG Exploit Kit Drive-by Infection Delivering KPOT Stealer

Executive Summary: Forensic examination of network traffic evidence revealed an automated drive-by compromise cycle. Workstation 10.0.76.109 (hostname BANGKOK-8AC2-PC) was redirected to RIG Exploit Kit delivery infrastructure at 37.46.135.170. Following client-side exploitation, an executable payload identified as KPOT Stealer was delivered. The compromised host initiated DNS resolution for fghjkmgru34.site (resolved to 8.209.83.76) and commenced credential exfiltration via periodic HTTP POST beacons targeting /gate.php.

5. Incident Response & Containment Recommendations

  • Perimeter Defense: Block outbound traffic to 37.46.135.170 and 8.209.83.76. Implement sinkholing for fghjkmgru34.site.
  • Endpoint Remediation: Isolate workstation 10.0.76.109 (BANGKOK-8AC2-PC). Image workstation memory and storage for offline root-cause confirmation.
  • Credential Revocation: Assume browser-stored passwords and active session tokens are compromised; mandate enterprise-wide credential resets and verify MFA.

6. Investigation Scope & Forensic Limitations

Network packet captures provide authoritative visibility into unencrypted wire transactions (DNS queries, plain HTTP headers, and initial payload downloads). However, encrypted TLS sessions, endpoint internal process trees, and exact exploit memory artifacts cannot be definitively confirmed from network captures alone without accompanying endpoint memory/disk forensic images.
